# OS Project using LPC1768

## Overview

This project implements an Operating System project using the
LPC1768 microcontroller and Keil development environment.

## Hardware / Platform

- LPC1768 Microcontroller
- ARM Cortex-M3
- Keil µVision

## Software Used

- Keil µVision
- Embedded C
- ARM Assembly

## Project Files

- `os_code.c` – Main OS source code
- `1768.c` – LPC1768-related source code
- `startup_LPC17xx.s` – Startup assembly file
- `os.uvproj` – Keil project file
- `os.uvopt` – Keil project options
- `os.hex` – Compiled HEX file

## Description

The project was developed as an embedded systems/operating systems
implementation for the LPC1768 microcontroller using the Keil
development environment.

## How to Open

1. Install Keil µVision.
2. Open `os.uvproj`.
3. Build the project using the Keil IDE.
4. Program the LPC1768 using the generated HEX file.
